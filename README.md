This directory contains a Rocq formalization of "Definitional Inversion, Without Normalisation"

The file [theorem-index](theorem-index.md) connects the maps the theorems in the paper to the results of this formalization. 

The file [three_way_comparison](three_way_comparison.md) is a side-by-side comparison of the Rocq, Agda and Lean developments.


==============================

This formalization compiles using The Rocq Prover, version 9.0.1

Building this proof requires first installing the following 
packages via OPAM:
```
rocq-hierarchy-builder
rocq-autosubst-ocaml 
rocq-smpl  
```
